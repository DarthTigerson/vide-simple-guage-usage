# Simple Gauge for vIDE

The classic look for the usage panel: two ring gauges with the burn rate and an estimate of when you will run out.

## What it looks like

- A ring gauge for your session and one for your week, each showing the percentage used
- Under each ring, when the window resets, as a date and time and a countdown
- A Burn rate column showing how fast you are using each window, in percent per hour
- An Est. run out column showing when each window is predicted to hit its limit, or "on track" if it will not before the reset

## How to use it

Right-click the usage panel, choose View, then Simple Gauge. Choose Bars in the same menu to go back to the built-in look. Uninstalling the app also returns the panel to Bars.

## Needs

vIDE 0.3.7 or later. The app only draws the gauges; the numbers come from vIDE's own usage tracking.
